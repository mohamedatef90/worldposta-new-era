Drop it in

Three implementation paths. Same tokens, same look.

React + Tailwind

// Use Tailwind classes that read the CSS variables
<button className="bg-brand-green hover:bg-brand-green-light text-white px-6 py-3 rounded-md font-semibold transition-all duration-200">
  Get started
</button>

Angular + Bootstrap

// In styles.scss
@import 'design-system.css';     // CSS variables (theme switch)
@import 'bootstrap-overrides';   // $primary: $brand-green; etc.

// In template
<button class="btn btn-primary">Get started</button>

Plain HTML

<link rel="stylesheet" href="design-system.css">
<html data-theme="dark">
  <button class="ds-btn ds-btn--primary">Get started</button>
</html>
